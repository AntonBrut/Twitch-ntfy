## Twitch-ntfy v0.1

Получай сообщения из чата Twitch прямо в приложение [ntfy](https://ntfy.sh) в реальном времени.

### Возможности

- Подключение к чату Twitch через IRC (анонимно, без OAuth)
- Каждое сообщение мгновенно отправляется в ntfy
- Опциональная поддержка бейджей пользователя (broadcaster, subscriber и т.д.)
- Автоматический реконнект при обрыве соединения
- Своя тема (topic) для каждого канала

### Установка

**Через Python:**
1. Установи Python 3.10+
2. Склонируй репозиторий
3. `pip install -r requirements.txt`
4. Заполни настройки в `env`
5. Запусти `python twitch_ntfy.py` или `run.bat`

**Через exe:**
1. Скачай `twitch-ntfy.exe` из релиза
2. Заполни настройки в `env`
3. Запусти `twitch-ntfy.exe`

### Настройка (файл `env`)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `TWITCH_CHANNEL` | Канал для подключения (без #) | — |
| `NTFY_TOPIC` | Тема для уведомлений | — |
| `NTFY_SERVER` | Адрес сервера ntfy | `https://ntfy.sh` |
| `NTFY_TOKEN` | Токен (нужен для приватных топиков) | — |
| `SHOW_BADGES` | Показывать бейджи (`true`/`false`) | `false` |
